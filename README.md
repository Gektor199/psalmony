# Psalmony

Пространство музыкальной группы: репертуар, аранжировки, сет-листы, подготовка выступлений и совместные репетиции. **0.6.2 — бета-версия.** PostgreSQL — единственная серверная база; приложение и база запускаются через Docker Compose.

## Быстрый запуск

```sh
git clone https://github.com/Gektor199/psalmony.git
cd psalmony
cp .env.example .env
docker compose up -d --build
```

Сайт: http://127.0.0.1:3180/. Приложение: http://127.0.0.1:3180/app. Зарегистрируйте аккаунт (логин, email, пароль, капча), затем создайте пустую группу или примите приглашение. Гостевого входа нет. Один аккаунт может владеть несколькими группами и участвовать в других.

По умолчанию локальные порты доступны только этому компьютеру. PostgreSQL и вложения хранятся в отдельных volumes. Остановка: `docker compose stop`, запуск: `docker compose up -d`. **Не удаляйте volumes при обновлении.**

## Что можно делать

- Вести песни и альбомы, загружать обложки/аватары, искать по тексту, хранить ноты и аудио.
- Импортировать ChordPro/TXT, транспонировать аккорды, использовать каподастр и Nashville numbers. Собирать аранжировки из блоков и повторов.
- Готовить сет-листы с песнями, паузами, заметками, датой и местом. Открывать сценический режим и следовать за ведущим группы.
- Сохранять программу с вложениями офлайн; работать с метрономом, тюнером, PDF/MusicXML и репетиционным плеером.
- Приглашать музыкантов одноразовыми ссылками, выдавать роли редактора/наблюдателя, отзывать доступ, передавать владение и выходить из групп.
- Менять пароль, завершать другие сессии, экспортировать собственный профиль и удалять аккаунт после передачи или удаления принадлежащих ему групп.
- Использовать настольный Studio: фейдер входа, локальное прослушивание устройства без сервера, собственный возврат и каналы участников с сервера, панорама, Mute/Solo, выходной микс и показатели сети.

## Данные и доступ

Сервер проверяет роли и принадлежность к группе. Оптимистическая блокировка сохраняет конфликтующие версии для явного разрешения. Локальные черновики привязаны к аккаунту и группе; серверное сохранение и сохранение на устройстве — разные состояния.

JSON-экспорт библиотеки содержит тексты, сет-листы и ссылки на медиа, **не сами медиафайлы**. Экспорт профиля содержит собственные данные и членства. Передача владения не удаляет материалы; удаление аккаунта сохраняет вклад в чужие группы. Отдельное удаление группы владельцем удаляет её общие материалы после явного подтверждения.

## Платформы и ограничения

PWA работает в поддерживаемых браузерах на телефонах и компьютерах. Установка и доступ к устройствам зависят от ОС и браузера. Для UDP-звука нужен отдельный настольный клиент macOS/Windows; браузерная PWA не заменяет его.

Комната рассчитана на восемь подключений. Синтетические проверки не доказывают комфортную совместную игру восьми музыкантов. Ping/Jitter относятся к сети, Delay — оценка, не измеренная полная задержка. Для проб используйте проводные наушники и стабильную сеть.

Mac — universal, ad-hoc подпись без нотариализации. Windows — unsigned; кросс-сборка не заменяет проверку на физическом Windows. Это не релиз App Store/Google Play.

**Почтовый сервис пока не подключён:** подтверждение email и восстановление забытого пароля письмом недоступны. Используйте уникальный пароль и сохраните его в менеджере паролей. Юридические страницы — явно обозначенные черновики; публичные реквизиты владелец пока не предоставил для публикации. [Правовой разбор и открытые вопросы](docs/LEGAL-REVIEW.md).

## Проверка

```sh
npm ci
npm run check
npm test
cargo test --manifest-path desktop/src-tauri/Cargo.toml
```

Интеграционные наборы требуют отдельной тестовой PostgreSQL и тестового API: задайте `DATABASE_URL`, `TEST_BASE` и `IDENTITY_TEST_BASE` по [инструкции](docs/INSTALL.md). Без этих переменных часть проверок пропускается. Не используйте production для тестового заполнения.

Исторические Jamulus-пилоты и предыдущие возможности перенесены в [HISTORY.md](docs/HISTORY.md); они не являются инструкцией текущего развёртывания. Исходные образцы текстов и оформления оригинальные. Лицензии браузерных библиотек находятся в `public/vendor/`.
